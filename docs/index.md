# notio

`notio` is a lightweight, project-agnostic CLI for creating templated Markdown notes and maintaining browsable log indexes.

It helps a project create and maintain a repo-local notes workspace with:

- configurable note types
- predictable file naming
- template-driven Markdown generation
- repo-local index pages for note folders
- thin Make wrappers when a project wants them

The docs follow the Diataxis structure:

- Tutorials: end-to-end guided paths
- How-to guides: task-focused recipes
- Explanation: design choices and scope
- Reference: exact commands and file layout
